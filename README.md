# 寻访实验台

用同一份岗位必要条件，比较两条寻访路线。输入搜索方向、用时和人工复核记录，查看去重样本、重合、符合数和主要证据缺口。

## 试用

运行 `node serve.mjs`，打开 `http://127.0.0.1:4394/`。首次载入虚构样本，改动保存在当前浏览器。候选人用匿名代号；同一个人在两条路线中使用同一个代号。

比较使用每小时独有符合样本数，重合样本单列。同一路线内，重复代号只算一人，冲突结论列为待核实。待核实不计入符合。主要缺口来自人工录入；并列缺口一起显示。一轮数据用于决定下一轮先试什么，不推断长期效果。

页面不连接招聘平台，不自动复核候选人。运行测试：`node --test`。
